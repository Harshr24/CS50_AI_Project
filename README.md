# CS50 AI with Python – Complete Solutions

**GitHub Repository:** [CS50 AI Project](https://github.com/Harshr24/CS50_AI_Project)

**CS50’s Introduction to Artificial Intelligence with Python** is a course offered by **Harvard University** that covers foundational concepts in artificial intelligence, including **search algorithms, knowledge representation, probability, machine learning, and natural language processing**.

This repository contains **complete solutions** for all projects in the course. Each project includes:

- Fully implemented Python solutions demonstrating key AI concepts in action.
- The original problem statements in PDF format for reference.

This repository serves as both a **learning resource** for others and a **portfolio** showcasing my expertise in artificial intelligence.

---

## Repository Content

The repository is organized as follows:

| Project            | Topics Covered                          | Description                                             |
|--------------------|-----------------------------------------|---------------------------------------------------------|
| **Search**         | BFS, DFS, A* Search                     | Implementation of AI-driven search algorithms.          |
| **Knowledge**      | Logic & Inference                       | Representing AI knowledge using propositional logic.    |
| **Uncertainty**    | Probability, Bayesian Networks          | Understanding uncertain data using probabilistic models. |
| **Optimization**   | Reinforcement Learning                  | Training AI agents to make optimal decisions.           |
| **Machine Learning** | Supervised Learning, Scikit-Learn     | Implementation of machine learning models.              |
| **Neural Networks** | Deep Learning, TensorFlow              | Building AI models using neural networks.               |
| **NLP**            | Natural Language Processing            | Processing and understanding human language with AI.    |

Each folder contains:

- **Python Code** – My implementation of the project.
- **PDF File** – The original problem statement for reference.
